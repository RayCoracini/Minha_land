# 🌐 Landing Page Pessoal

Landing page pessoal criada com o objetivo de praticar e aprimorar habilidades em **HTML** e **CSS**.

## 📖 Sobre o Projeto

Este projeto foi desenvolvido como forma de estudo e prática de front-end.  
Atualmente utiliza apenas **HTML** e **CSS**, com importação de fontes externas.  

A intenção é evoluir o projeto futuramente, adicionando JavaScript e novas funcionalidades.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Fonts externas

## ▶️ Como Visualizar

Como o projeto não possui dependências, basta abrir o arquivo principal no navegador:

1. Abra a pasta do projeto
2. Clique duas vezes no arquivo `index.html`

ou 

acessar: https://raycoracini.github.io/Minha_land/

> Dica: Utilize a extensão **Live Server** no VS Code para uma melhor experiência de desenvolvimento.
